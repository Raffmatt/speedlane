# Speed Lane

A browser game about running a used-car dealership, built as a single
self-contained HTML file. No build step and no dependencies to install.

## Play it

Open `public/index.html` in a browser, or visit the GitLab Pages URL for this
project. Sign in, or use **Continue as guest** for a throwaway run.

## What is in here

- `public/index.html` — the whole game: 3D scene, UI, missions and assets.
- `.gitlab-ci.yml` — publishes `public/` to GitLab Pages on the default branch.

The field research this game is based on is deliberately **not** in this
repository: it contains interview recordings and transcripts of named people.
